## 💻 How to Use This Repository

### Prerequisites
```bash
Python 3.8+
Jupyter Notebook
```

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/mohammedsaniya55-hash/Cognifyz_intern.git
   cd Cognifyz_intern
   ```

2. **Install Required Packages**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch Jupyter Notebook**
   ```bash
   jupyter notebook
   ```

4. **Open Any Project Notebook**
   - Navigate to the desired project folder
   - Open the `.ipynb` file
   - Run cells to explore the project
