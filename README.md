# 🍽️ Cognifyz Technologies Internship

## Restaurant Data Analysis using Python

This repository contains the tasks completed during my **Artificial Intelligence Internship at Cognifyz Technologies**.

The project focuses on exploring restaurant data using Python and performing data analysis, visualization, and feature engineering to gain meaningful business insights.

---

## 📌 Project Overview

During this internship, I worked with a restaurant dataset to analyze:

- Restaurant ratings
- City-wise restaurant distribution
- Cuisine popularity
- Online delivery availability
- Table booking trends
- Price range analysis
- Feature engineering

The project demonstrates practical use of Python for real-world data analysis.

# 📈 Key Insights

Some important observations from the analysis:

- Most restaurants do not provide table booking.
- Online delivery is available only for a subset of restaurants.
- Restaurants with table booking generally have higher average ratings.
- Higher price range restaurants tend to receive better ratings.
- Feature engineering improves the dataset for future predictive analysis.
